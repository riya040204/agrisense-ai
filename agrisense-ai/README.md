# AgriSense AI

IoT-powered crop advisory system for Soybean (Kharif) & Wheat (Rabi) in Madhya Pradesh.

## Team & Roles
| Student | Role | Owns |
|---|---|---|
| | IoT & Hardware | Sensor data → backend (manual entry for now, faculty-provided values) |
| | Backend & Database | FastAPI + database + agri-logic engine |
| | Mobile App | Flutter app (Dashboard, History, Advisory Feed) |
| | Data / Agri-Logic (optional) | NPK ranges, irrigation & pest rules, test cases |

## 8-Parameter Data Contract
Fill this in as a team in Week 1 — this is the single source of truth every screen and endpoint must match exactly.

| Field | Type | Unit | Valid Range | Notes |
|---|---|---|---|---|
| soil_type | string | — | e.g. "black_cotton", "alluvial" | |
| nitrogen | float | kg/ha | | |
| phosphorus | float | kg/ha | | |
| potassium | float | kg/ha | | |
| soil_moisture | float | % | 0–100 | |
| temperature | float | °C | | |
| humidity | float | % | 0–100 | |
| district | string | — | | must match your shortlisted 5–6 MP districts |
| crop | string | — | "soybean" or "wheat" | |
| timestamp | datetime | ISO 8601 | | auto-generated by backend |

## Current Data Source
Sensor readings are currently entered manually via the FastAPI `/docs` page, using values
supplied by our faculty mentor. This will be replaced by live ESP32 hardware once available.

## Repo Structure
```
/backend   - FastAPI + database + agri-logic engine
/mobile    - Flutter app
/data      - sample/faculty-provided readings (CSV/JSON), test cases
```

## Running the backend locally
```
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```
Then open http://localhost:8000/docs to test endpoints.
